# Гонка чата для TikTok LIVE

Интерактивный эфир: кубические человечки бегут по яркой извилистой трассе
с препятствиями, а бегуны — зрители. Всё работает в облаке: сервер сам рисует
игру и сам шлёт видео со звуком в TikTok, компьютер и OBS не нужны.

## Что видят зрители

- **Написал в чат — человечек падает с неба на старт.** Забеги идут по кругу:
  ~20 секунд сбор → гонка на 1500 м (не короче минуты — `min_race_seconds`) →
  пьедестал → снова сбор.
- **Эпичный финиш.** Лидер у черты — слоу-мо и «аура-камера» облетает его,
  на финише — столб золотого света, волны, искры, золотая подсветка экрана и дроп
  в музыке. 2-е и 3-е места — короткий облёт и вспышка цвета медали. На
  результатах призёры танцуют на пьедестале, остальные лежат поверженные на фоне.
  Кто написал во время забега, попадает в следующий.
- **Трасса-серпантин с препятствиями** (иконки видны на мини-карте сверху):
  🔨 качающиеся молоты, 🌀 вращающаяся вертушка (сносит или перепрыгивается),
  ⛰️ трамплины, ⏩ ускоряющие дорожки, 🟢 слизь, которая тормозит.
  Столкновения честные, по геометрии: молот отшвыривает вбок по ходу замаха,
  вертушка — по дуге; бегун кувыркается и потом возвращается на свою дорожку.
  Через вертушку иногда успевают перепрыгнуть, в джетпаке препятствия не страшны.
- **Кинематографичная камера-режиссёр** сама склеивает планы: спереди на лидера,
  из-за спины, сбоку «телевиком», дрон сверху, низкий план у земли, засада у
  препятствия перед подбегающими, крупный план и слоу-мо на молнии/ядерке,
  фотофиниш. В лобби — пролёт над трассой.
- **Баффы** (настраиваются в `config.json`):

  | Что сделал зритель | Что происходит |
  |---|---|
  | ❤️ лайк | лёгкое ускорение + сердечко над бегуном |
  | ➕ подписка | ТУРБО ×2.2 на 5 секунд |
  | 🔁 репост, 🫰 Finger Heart, подарок от 10💎 | 🚀 ДЖЕТПАК: взлетает и пролетает вперёд |
  | 🌹 роза, 🎵 TikTok, любой подарок | ⚡ ТУРБО с огненным следом |
  | подарок от 30💎 | ⚡ МОЛНИЯ бьёт в лидера, он стоит 2.5 с |
  | подарок от 100💎 | ☢️ ЯДЕРКА: все стоят, отправитель летит вперёд |

- **АУРА и мем-титулы.** Лайки, подписки, подарки и победы копят ауру, по ней
  растёт титул над ником: `NPC → чилл гай → сигма → гигачад → МИФИК → ЛЕГЕНДА АУРЫ`.
  С «сигмы» бегун в очках 😎, с «гигачада» — нимб, с «МИФИКА» — светящаяся аура,
  у чемпиона стрима — корона. Аура хранится между эфирами, в лобби — таблица
  «Легенды ауры».
- **Свой Roblox-скин.** Пишешь в чат свой ник Roblox (одним словом латиницей)
  — сервер находит аватар через публичное API Roblox, и человечек получает твои
  цвета кожи, одежды и волос, принт футболки с рендера и твоё лицо. Скин
  запоминается между эфирами. Выключить — `"roblox_skins": false` в `config.json`.
- **Мемные лица и подписи.** У человечков куча выражений: NPC-взгляд, сигма-
  ухмылка, гигачад с челюстью, «deal with it», проклятые глаза, 😂, 💀, 🗿, 🤡,
  «сус», орущий, плачущий. Лицо меняется само: в турбо орёт от восторга, после
  удара — крестики, отстающий плачет, лидер ухмыляется. Над бегунами всплывает
  «−1000 АУРЫ», «+1000 АУРЫ», «NPC ПОВЕДЕНИЕ», «ОН ГОТОВИЛСЯ»…
- **Подарки видят все:** каждый подарок, подписка и репост — крупная карточка
  (кто, что, что даёт), камера на 3 секунды показывает этого бегуна, а в углу —
  «👑 ТОП ДАРИТЕЛЬ» эфира.
- **Мемы из чата.** 🗿, 💀, «сигма», «скибиди», «67», «аура», «имба», «gg»…
  показывают большой эмодзи над бегуном (🗿 и 💀 — ещё и с «бумом»).

## Музыка

Положи свои треки (`.mp3`, `.ogg`, `.m4a`, `.wav`) в папку `music/`. Музыка
подстраивается под то, что на экране:

- игра сама «слушает» каждый трек и находит **дроп** — момент, где трек выходит
  на самую мощную часть;
- каждый забег — новый трек: в лобби играет начало, за 3 секунды до старта
  музыка переходит на нарастание перед дропом, и **дроп падает ровно на «GO!»**;
- ☢️ ядерка и финишная прямая — полсекунды «затянутого» звука и снова дроп;
- на результатах музыка звучит глухо, как из-за стены.

Звуки эффектов (бонк, джетпак, молния, бум) синтезируются сами. Найденные
дропы запоминаются в браузере; если игра ошиблась с треком, проще всего
заменить его другим.

⚠️ TikTok LIVE глушит звук и может завершить эфир за музыку с авторскими правами.
Для эфиров бери треки с лицензией, разрешающей стримы (ищи «royalty free phonk» /
«no copyright phonk» и читай условия), или свои. В git треки не попадают.

## Проверить у себя (Mac, 5 минут)

Нужен **Python 3.10 или новее**. Встроенный в macOS `python3` — старый 3.9,
с ним не встанут зависимости. Поставь Python 3.12 с
[python.org](https://www.python.org/downloads/) (или `brew install python@3.12`)
и создавай окружение именно им:

```bash
git clone https://github.com/SantoSteffano/tiktok-live-race.git
cd tiktok-live-race
python3.12 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python server.py --demo
```

Открой http://localhost:8765 в Chrome и кликни по странице, чтобы включился
звук. Для музыки сначала положи треки в `music/`. В демо-режиме фейковые зрители пишут, лайкают и дарят подарки.

## Запуск в облаке

### 1. Ключ трансляции TikTok

Облачный сервер шлёт видео в TikTok по RTMP, как OBS, поэтому нужны
**адрес сервера (Server URL) и ключ трансляции (Stream key)**. Их дают не
всем аккаунтам: нужен доступ к LIVE (18+, условия по числу подписчиков
зависят от страны). Ищи их в LIVE Center / LIVE Producer на сайте TikTok
или в TikTok LIVE Studio. У многих аккаунтов ключ меняется на каждый эфир.
Тогда перед эфиром обнови `STREAM_KEY` в `.env` и перезапусти контейнер.

### 2. Сервер

Подойдёт обычный облачный сервер (VPS) с Linux, **от 4 ядер и 8 ГБ памяти**,
видеокарта не нужна. Это примерно 10–25 $ в месяц у Hetzner, DigitalOcean,
Timeweb и т.п. На 4 ядрах без видеокарты игра выдаёт около 20 кадров/с,
видео идёт 720×1280 при 30 кадрах/с.

```bash
# на сервере (Ubuntu): ставим Docker
curl -fsSL https://get.docker.com | sh

git clone https://github.com/SantoSteffano/tiktok-live-race.git
cd tiktok-live-race
cp .env.example .env
nano .env                # TIKTOK_USERNAME, RTMP_URL, STREAM_KEY

docker compose up -d --build
docker compose logs -f   # смотреть, что происходит
```

Сначала можно проверить без эфира: поставь в `.env` `DEMO=1`, допиши
`OUTPUT=/app/data/test.mp4` и `DURATION=30`, запусти, а потом скачай
`data/test.mp4` с сервера и посмотри. После этого убери эти строки.

Контейнер сам перезапускается при сбоях: браузер, ffmpeg и подключение к
чату переподключаются автоматически.

### Как это устроено

```
TikTok LIVE чат ──► server.py ──WebSocket──► Chromium (игра, web/)
                    (баффы, аура)                 │ виртуальный экран Xvfb
                                                  ▼
                              ffmpeg (картинка + звук) ──RTMP──► TikTok LIVE
```

| Файл | Что делает |
|---|---|
| `server.py` | Слушает эфир через неофициальную библиотеку [TikTokLive](https://github.com/isaackogan/TikTokLive), переводит события в баффы, считает ауру (`data/aura.json`). |
| `config.json` | Баффы, подарки, титулы, мем-слова, параметры забега. |
| `web/game.js` | 3D-игра на three.js: человечки, баффы, эффекты, раунды, интерфейс. |
| `web/track.js` | Извилистая трасса, окружение и препятствия. |
| `web/director.js` | Камера-режиссёр: планы и склейки. |
| `web/audio.js` | Плеер треков из `music/` и звуки эффектов. |
| `music/` | Твои треки. |
| `stream/start.sh` | Облачная трансляция: Xvfb + Chromium + pulseaudio + ffmpeg. |

## Настройка (`config.json`)

- `race` — длина трассы (`track_meters`, препятствия расставляются по ней сами), время лобби, максимум бегунов, сколько ботов.
- `effects` — что дают лайк, подписка, репост.
- `gifts_by_name` — конкретные подарки по английскому названию из TikTok (`rose`, `finger heart`…).
- `gifts_by_diamonds` — остальные подарки по цене: берётся самый дорогой подходящий уровень.
  Виды: `boost` (скорость ×`multiplier` на `seconds`), `jetpack` (+`meters`),
  `lightning` (лидер стоит `seconds`), `nuke` (все стоят `seconds`, отправитель летит на `meters`).
- `aura` — сколько ауры за лайк, подписку, репост, алмаз, победу. `titles` — пороги титулов.
- `emotes` — мем-слова и эмодзи, которые показываются над бегуном.

После правки перезапусти: `docker compose restart` (или `server.py` локально).

Параметры страницы: `?quality=low` — без свечения, для серверов без
видеокарты (в облаке включено по умолчанию; на компьютере с нормальной
видеокартой без него красивее — с тенями и свечением), `?mute` — без звука.

## Важно знать

- **TikTokLive — неофициальная библиотека.** Обновление TikTok может её
  сломать, тогда помогает `pip install -U TikTokLive` или пересборка
  контейнера. Иногда она просит ключ сервиса подписи (Euler Stream) — это
  будет видно в логах.
- **Правила TikTok.** Долгие эфиры без ведущего TikTok может ограничивать.
  Интерактивные игры — популярный формат, но правила LIVE стоит прочитать.
- Название и логотипы Roblox здесь не используются — это своя игра.
