# Музыка

Положи сюда свои треки (`.mp3`, `.ogg`, `.m4a`, `.wav`) — игра будет крутить
их по кругу в случайном порядке. Новые файлы подхватываются со следующего трека
после перезагрузки страницы.

⚠️ TikTok LIVE глушит звук и может завершить эфир за музыку с авторскими
правами. Для эфиров бери треки с лицензией, разрешающей стримы (ищи
«royalty free phonk» / «no copyright phonk» и читай условия), или свои.

Файлы из этой папки в git не попадают (см. `.gitignore`).
